The toolkit

Seven tools, built one at a time.

Each tool is released when it actually works. Planned tools are listed in build order.

  • Live

    Message Generator

    Gradients, hex colors and formatting for chat and config messages. Exports YAML for Hex, MiniMessage, Spigot, legacy and CMI formats.

    Open tool
  • Next

    MOTD Generator

    Design the two-line server list message with a live server-list preview.

  • Planned

    Rank Price Calculator

    Price VIP ranks by perks and audience, and compare tiers side by side.

  • Planned

    Crate Reward Generator

    Build weighted reward tables, check real drop odds and export configs.

  • Planned

    Economy Calculator

    Model shop prices, money supply and inflation before your economy breaks.

  • Planned

    Plugin Config Helper

    Fill in a form, get a valid config snippet for popular plugins.

  • Planned

    Enchantment Planner

    Organize custom enchantments: levels, rarity, conflicts and costs.

  • Runs in your browser

    No backend, no tracking, no account. Your configs never leave your device.

  • Made for real servers

    Output uses the formats Paper, Spigot and popular plugins actually read — tested, not guessed.

  • Open source

    MIT licensed. Read the code, self-host it, or send a pull request.
