Each tool does one job and gives you something you can paste into your server. Two are ready today and five more are being built in order.

Message Generator

Gradients, hex colors and formatting for chat messages, item lore and config files.

  • Up to 8 gradient colors, plus solid and rainbow
  • Six output formats for the plugins you already run
  • Placeholders like %player% are never split
  • YAML with nested keys and correct quoting

  • Turns any image into a 64 × 64 server icon

Output your plugins accept

Most generators stop at pretty colors. These tools handle the details that make a config work the first time.

Placeholders stay intact
Color codes inside %player_name% break PlaceholderAPI. Every placeholder gets one color, so it still resolves.
Formatting survives every color
In Minecraft a color code resets bold and italic. The generator repeats them after each color for you.
Nothing leaves your browser
No account, no tracking, no server. The code is open source under the MIT license.
