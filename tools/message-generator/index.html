Which format does my plugin need?

          

            

              
                
FormatLooks likeUse it for

              
              
                
Hex&#8ccfffHelloEssentialsX, TAB, DeluxeMenus and most modern plugins. Needs Minecraft 1.16+.

                
MiniMessage<gradient:#8ccfff:#a78bfa>Plugins built on Paper’s Adventure API. Shortest output, because the plugin computes the gradient.

                
Spigot hex&x&8&c&c&f&f&fPlugins that translate & codes with Bukkit’s built-in method. Needs 1.16+.

                
Legacy&bHelloEvery plugin and every version. Gradients use the closest of the 16 classic colors.

                
Section sign§x§8§c…Places that read raw formatting codes and don’t translate &.

                
CMI{#8ccfff}HelloCMI and plugins that use CMILib.

              
            

          

        


        

          
Questions

          

            

              My message shows the codes instead of colors.
              
Your plugin doesn’t read that format. Pick another one from the table above; Legacy works everywhere. Hex colors also need the server and the player’s game on Minecraft 1.16 or newer.

            

            

              Why is &l repeated after every color?
              
In Minecraft, a color code resets formatting. To keep a gradient bold, the bold code has to follow every color code. The generator does this for you.

            

            

              Should I use single or double quotes?
              
Single quotes are the safest choice: YAML reads everything inside them literally. Double quotes treat backslashes as escapes, which the generator handles if you pick them.

            

            

              Is my text sent anywhere?
              
No. Everything runs in your browser. Your message is only stored in the share link, and only if you copy it.
