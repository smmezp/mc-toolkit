How to use it on your server

          
    
            
  1. Write and styleType your message, choose colors and formatting. The preview shows how it renders in game.
    2. 
            
  2. Pick your plugin's formatCheck your plugin's documentation for the color format it reads. When unsure, &#RRGGBB is the most widely supported.
    3. 
            
  3. Paste and reloadCopy the YAML into the plugin's config file, keep the indentation, then reload the plugin or restart the server.

Which format does my plugin need?

          

            

              
                
FormatLooks likeUse it for

              
              
                
Hex&#8ccfffHelloEssentialsX, TAB, DeluxeMenus and most modern plugins. Needs Minecraft 1.16+.

                
MiniMessage<gradient:#8ccfff:#a78bfa>Plugins built on Paper's Adventure API. Shortest output; the plugin computes the gradient itself.

                
Spigot hex&x&8&c&c&f&f&fPlugins that translate & codes with Bukkit's built-in method. Needs 1.16+.

                
Legacy&bHelloEvery plugin and every version. Gradients are approximated with the 16 classic colors.

                
Section sign§x§8§c…Places that read raw formatting codes and don't translate &.

                
CMI{#8ccfff}HelloCMI and plugins that use CMILib.

              
            

          

        


        

          
Questions

          

            

              My message shows the codes instead of colors.
              
The plugin doesn't read that format. Try another one from the table above — Legacy works everywhere. Hex colors also need the server and the player's client on Minecraft 1.16 or newer.

            

            

              Why is &l repeated after every color?
              
In Minecraft, a color code resets formatting. To keep a gradient bold, the bold code has to follow every color code. The generator handles this for you.

            

            

              Should I use single or double quotes?
              
Single quotes are the safest choice: YAML treats everything inside them literally. Double quotes interpret backslashes, which the generator escapes for you if you pick them.

            

            

              Is my text sent anywhere?
              
No. Everything runs in your browser. The only thing that stores your message is the share link, and only if you copy it.
