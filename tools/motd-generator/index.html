Questions

          

            

              Why does my gradient look different in server.properties?
              
The motd setting only understands the 16 classic Minecraft colors, so each letter gets the closest one. For smooth hex gradients, use MiniMOTD on Paper or Spigot, or the Velocity target on a proxy.

            

            

              What happens if a line is too wide?
              
The server list fits about 270 pixels per line. Longer text wraps onto the next line, and anything past the second line is hidden. The width meter and the preview show this before you paste.

            

            

              Why is centering done with spaces?
              
Minecraft has no centering setting for the MOTD. The generator measures each line with the game’s font and adds the right number of spaces in front, the same thing server owners do by hand.

            

            

              How do I add a server icon?
              
Save a 64 × 64 PNG named server-icon.png in the server’s main folder, next to server.properties, then restart. Use “Check an image” above to test yours or convert it to the right size.
